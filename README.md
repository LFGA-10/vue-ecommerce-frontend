# Lumina E-commerce Frontend 🛍️

A minimalist, high-performance e-commerce storefront built with Vue 3 and Vite, focusing on ultra-clean aesthetics and smooth user interactions.

![Storefront Preview](https://images.unsplash.com/photo-1441986300917-64674bd600d8?auto=format&fit=crop&q=80&w=1000)

## ✨ Features
- **Minimalist Aesthetic**: Clean typography and generous whitespace for a premium feel.
- **Vue 3 Composition API**: Modern, scalable state management and component logic.
- **Dynamic Product Grid**: Filterable product lists with interactive hover states.
- **Responsive Design**: Fluid layout optimized for all screen sizes.
- **High Performance**: Lightning-fast load times powered by Vite.

## 🚀 Tech Stack
- **Framework**: Vue 3 + Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide Vue Next
- **Language**: TypeScript

## 🛠️ Installation
```bash
npm install
npm run dev
```
